# Recoil Jump Man — Android

점프 버튼 없이 총의 반동으로 이동하고 싸우는 2D 액션 메트로베니아. Galaxy S24 Ultra에서 조작감을 시험하며 개발합니다.

## 조작 패치 0.1.2

**네 가지 조작 방식**을 선택하며 비교합니다. 기존 캐릭터/화면 중앙 조준에 우측 하단 **작은 원이 있는 AIM PAD / 작은 원이 없는 TOUCH CIRCLE**을 추가했습니다. 두 패드 모드는 모든 총을 길게 눌러 발사하며, 중심 복귀와 손 떼기로 멈춥니다. 왼쪽 전체 RELOAD도 추가했습니다.

[0.1.2 변경·설치 안내](docs/release-0.1.2.md) · [소스 구조와 수치](docs/architecture.md) · [이전 APK 검증 기록](docs/validation-0.1.1.md)

APK는 자동 Android 실행 검증을 통과한 뒤 Releases에서 최신 APK를 내려받아 설치합니다. 테스트 서명이 기존 앱과 다르면 **기존 앱을 삭제한 뒤 설치**해야 하며 앱 내부 체크포인트가 초기화됩니다.

1. 같은 구간을 3 AIM PAD / 4 TOUCH CIRCLE로 이동하고 작은 원의 유무를 비교합니다.
2. 패드 중심 복귀·손 떼기 때 사격이 멈추는지 확인합니다.
3. 리볼버를 홀드로 비운 뒤 자동 교체가 이어지는지 확인합니다.
4. 왼쪽 RELOAD·모든 총 소진 예약 후 실제 손을 떼야 재발사되는지 확인합니다.
5. 패드+BRACE 동시 입력과 패드 밖 핀치, 뒤로가기·재기동 설정 유지를 확인합니다.

리볼버·샷건·SMG와 원본 디버그 월드를 사용합니다. 체크포인트는 안전 위치·설정을 복원하며 새 기동 시 체력·탄창·적은 초기화합니다. UI는 영어이며 스킬·아이템·스토리·자이로는 아직 없습니다. 실기기 조작감·장시간 성능은 사용자 테스트로 확인합니다.
