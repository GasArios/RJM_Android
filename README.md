# Recoil Jump Man — Android

점프 버튼 없이 총의 반동으로 이동하고 싸우는 2D 액션 메트로베니아. Galaxy S24 Ultra에서 조작감을 시험하며 개발합니다.

## 조작 패치 0.1.2

기존 캐릭터/화면 중앙 조준에 우측 하단 **작은 원이 있는 AIM PAD / 작은 원이 없는 TOUCH CIRCLE**을 추가했습니다. 두 패드 모드는 모든 총을 길게 눌러 발사하며, 중심 복귀와 손 떼기로 멈춥니다. 왼쪽 전체 RELOAD도 추가했습니다.

**[APK 바로 다운로드 — 약 6.5MB](https://github.com/GasArios/RJM_Android/releases/download/android-prototype-6/RJM-Android-0.1.2.apk)** · [릴리스](https://github.com/GasArios/RJM_Android/releases/tag/android-prototype-6) · [검증 기록](docs/validation-0.1.2.md)

자동 행동 검증과 Android 15 네이티브 터치 검증을 통과했습니다. Galaxy용 ARM64 코드가 포함되어 있습니다.

## 조작

뒤로가기 → **CONTROL**로 1→2→3→4→1 순서로 변경합니다. 모드와 배율은 저장하며 초기 기본값은 캐릭터 기준입니다.

| 모드 | 조준 기준 | 사격 |
|---|---|---|
| 1 CHARACTER | 캐릭터의 화면 위치 | 반자동 탭, SMG 홀드 |
| 2 SCREEN CENTER | 게임 화면 중앙 | 1번과 같음 |
| 3 AIM PAD | 우측 하단 고정 원 중심, 작은 원 표시 | 모든 총 홀드, 드래그로 방향 변경 |
| 4 TOUCH CIRCLE | 3번과 같은 중심, 작은 원 없음 | 3번과 같음 |

3·4번은 원 안 어디서든 누릅니다. 중심 바깥에서는 발사하고 중심으로 돌아오거나 손을 떼면 멈춥니다. 원 바깥까지 드래그해도 조준이 이어집니다. 당긴 길이는 반동·공격 간격을 바꾸지 않습니다. 패드 밖 화면 탭은 발사하지 않습니다.

| 입력 | 동작 |
|---|---|
| 두 패드 밖 게임 영역 손가락을 벌림/모음 | 확대/축소. UI 크기는 유지, 배율 0.65~1.80 저장 |
| 빈 총의 다음 사격 입력 | 원본 슬롯 순서로 다음 발사 가능한 총 선택 |
| 모든 총 소진 후 1·2번 새 탭 / 3·4번 홀드 | 전체 재장전 예약. 착지 후 원본 평균 시간으로 장전 |
| 왼쪽 RELOAD | 부분 탄창도 전체 장전/예약. 현재 홀드를 차단 |
| GUNS | 8% 슬로모션 수동 총 선택, RELOAD ALL GUNS로 전체 장전/예약 |
| BRACE 홀드 | 지상 버티기. 다른 손가락 사격과 함께 사용 |
| Android 뒤로가기 | 일시정지, CONTROL 선택·배율 초기화·저장 |
| 일시정지 버튼 바깥 두 손가락 | 사격 없이 배율 조절 |

재장전 요청 뒤에는 **실제 손을 떼고 새로 눌러야** 발사합니다. 중심 왕복만으로 차단을 풀지 않습니다. 1·2번의 SMG에서 반자동 총으로 교체되면 새 탭이 필요하고, 3·4번은 모든 총을 홀드로 이어서 발사합니다. 반동은 지정한 원본 방향이며 보정은 탄환에만 적용합니다.

핀치 중 사격을 막고 세계는 8% 시간으로 진행합니다. 모든 손가락을 뗀 뒤 새로 사격합니다. 1·2번에서 첫 손가락을 눌러 처리한 뒤 두 번째를 붙이면 이미 첫 발이 나갈 수 있으므로 일시정지 핀치로 안전하게 배율을 조절할 수 있습니다. 패드·왼쪽 버튼 포인터는 핀치에 포함하지 않습니다.

## 설치와 이번 테스트

위 링크에서 `RJM-Android-0.1.2.apk`를 내려받아 설치합니다. 이번 APK는 기존 0.1.1과 서명이 다르므로 **기존 앱을 삭제한 뒤 설치**해야 하며 앱 내부 체크포인트가 초기화됩니다.

1. 같은 구간을 3 AIM PAD / 4 TOUCH CIRCLE로 이동하고 작은 원의 유무를 비교합니다.
2. 패드 중심 복귀·손 떼기 때 사격이 멈추는지 확인합니다.
3. 리볼버를 홀드로 비운 뒤 자동 총 교체가 이어지는지 확인합니다.
4. 왼쪽 RELOAD·모든 총 소진 예약 후 실제 손을 떼야 재발사되는지 확인합니다.
5. 패드+BRACE 동시 입력과 패드 밖 핀치, 뒤로가기·재기동 설정 유지를 확인합니다.

리볼버·샷건·SMG와 원본 디버그 월드를 사용합니다. 체크포인트는 안전 위치·설정을 복원하며 새 기동 시 체력·탄창·적은 초기화합니다. UI는 영어이며 스킬·아이템·스토리·자이로는 아직 없습니다. 실기기 조작감·장시간 성능은 사용자 테스트로 확인합니다.
