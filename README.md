# Recoil Jump Man — Android

점프 버튼 없이 총의 반동으로 이동하고 싸우는 2D 액션 메트로베니아. Galaxy S24 Ultra에서 조작감을 시험하며 개발합니다.

## 조작 패치 0.1.1

첫 APK의 실기기 피드백을 반영해 **핀치 확대·전체 화면 비율·조준 기준 선택·원본 자동 총 교체와 전체 재장전**을 구현했습니다. 새 APK는 자동 행동 검증과 Android 에뮬레이터 검증을 통과한 뒤 [Releases](https://github.com/GasArios/RJM_Android/releases)에 공개합니다.

## 조작

| 입력 | 동작 |
|---|---|
| 게임 영역 탭 | 조준 모드에 따른 방향으로 사격, 반대 방향으로 반동 이동 |
| SMG 홀드 | 연사. 방향 유지, 의도적으로 드래그하면 변경 |
| 두 게임 영역 손가락을 벌림/모음 | 확대/축소. UI 크기는 유지. 배율 저장 |
| 빈 총에서 다음 사격 입력 | 원본 슬롯 순서로 다음 발사 가능한 총 자동 선택 |
| 모든 총이 비었을 때 새 탭 | 전체 재장전 예약. 착지 후 원본 평균 시간으로 재장전 |
| GUNS | 8% 슬로모션 수동 총 선택. RELOAD ALL GUNS는 전체 재장전/예약 |
| BRACE 홀드 | 지상 버티기. 다른 손가락 사격과 함께 사용 가능 |
| Android 뒤로가기 | 일시정지. AIM MODE로 캐릭터/화면 중앙 기준 변경, 배율 초기화, 저장 |
| 일시정지에서 버튼 바깥의 두 손가락 | 사격 없이 배율 조절 |

기본 배율은 1.10, 조준은 캐릭터 기준입니다. 중앙 기준은 **게임 영역 중앙에서 터치 위치로 향하는 방향**을 입력합니다. 적을 직접 터치해도 캐릭터에서 그 적을 향해 발사하는 방식과 다릅니다. 작은 중앙 원 내부는 새 사격을 하지 않습니다.

핀치 중 사격을 막고 세계는 8% 시간으로 진행합니다. 손가락을 모두 떼고 새로 눌러 사격합니다. 즉시 발사를 유지하므로 플레이 중 두 번째 손가락을 붙이기 전 첫 발이 나갈 수 있습니다. 일시정지 핀치는 안전합니다. SMG에서 반자동 총으로 자동 교체되면 새로 탭해야 합니다.

## 설치와 이번 테스트

Releases에서 `RJM-Android-0.1.1.apk`를 내려받아 설치합니다. 테스트 서명 키가 이전 빌드와 다르면 기존 앱을 삭제하고 설치해야 하며 앱 내부 체크포인트가 초기화됩니다.

1. 캐릭터 기준 / 중앙 기준으로 같은 구간을 이동하고 가장자리에서 좌우·상하 방향을 비교합니다.
2. 일시정지 중 편한 배율을 찾고, 재기동 뒤 설정이 유지되는지 확인합니다.
3. 리볼버를 비운 뒤 다음 탭으로 샷건을 사용하고, 공중에서 수동 선택도 시험합니다.
4. GUNS의 전체 재장전과 모든 탄 소진 후 착지 예약을 확인합니다.
5. BRACE와 사격 동시 입력, 핀치 후 한 손가락만 남겼을 때 오발 여부를 확인합니다.

리볼버·샷건·SMG와 원본 디버그 월드를 사용합니다. 체크포인트는 안전 위치·설정을 복원하며 새 기동 시 체력·탄창·적은 초기화합니다. UI는 영어이며 스킬·아이템·스토리·자이로는 아직 없습니다. 실기기 조작감·장시간 성능은 사용자 테스트로 확인합니다.
