# Recoil Jump Man — Android

점프 버튼 없이 총의 반동으로 이동하고 싸우는 2D 액션 메트로베니아.

이 저장소는 RJM의 Android 앱 개발용 저장소입니다. 기본 타깃 기기는 Samsung Galaxy S24 Ultra이며, 개발자는 휴대폰에서 변경 내용을 확인하고 APK를 실행하는 환경을 사용합니다.

## 현재 상태

첫 Android APK **0.1.0**을 만들었고 빌드·서명·Android 15 에뮬레이터 설치/실행 검증이 통과했습니다. Galaxy S24 Ultra용 ARM64 코드가 포함되어 있습니다. 실기기 조작감·성능 검증은 별도로 진행합니다.

**[APK 바로 다운로드 — 약 6.4MB](https://github.com/GasArios/RJM_Android/releases/download/android-prototype-3/RJM-Android-0.1.0.apk)** · [릴리스](https://github.com/GasArios/RJM_Android/releases/tag/android-prototype-3) · [검증 기록](docs/validation-0.1.0.md)

## 설치와 조작

Releases에서 `RJM-Android-0.1.0.apk`를 휴대폰으로 내려받아 설치하세요. 다운로드한 브라우저 또는 파일 앱의 설치 허용을 켜야 할 수 있습니다.

| 입력 | 동작 |
|---|---|
| 게임 화면 탭 | 누른 방향으로 사격, 반대쪽으로 반동 이동 |
| SMG를 누르고 있기 | 연사. 처음 잡은 방향 유지, 드래그하면 방향 변경 |
| 빈 탄창에서 새 탭 | 착지 후 재장전 예약. 예약 뒤 손을 떼고 새 입력으로 사격 |
| BRACE 홀드 | 지상 버티기. 다른 손가락으로 사격 가능 |
| GUNS | 8% 슬로모션 총 선택. 총마다 탄창 유지 |
| Android 뒤로가기 | 일시정지 메뉴. 설정·안전 체크포인트 저장·필드 재시작 |
| HELP | 조작 설명 |

리볼버·샷건·SMG와 원본 디버그 월드를 사용합니다. 스킬·아이템·스토리·자이로는 아직 없습니다. 체크포인트는 안전 위치를 복원하고 체력·탄창·적은 다시 초기화합니다. UI 글자는 영어입니다.

## 확인해 주세요

1. 캐릭터 아래를 탭하면 위로 떠오르는지, SMG 홀드 방향이 카메라 이동으로 바뀌지 않는지.
2. 공중에서 빈 탄창을 탭한 뒤 착지하면 재장전하고, 손을 떼기 전에는 자동 발사가 안 되는지.
3. GUNS 선택과 메뉴 닫기 터치가 총알을 발사하지 않는지.
4. 뒤로가기 제스처·홈 화면·앱 전환 후 일시정지가 유지되는지.
5. 10분 실행 후 FPS·발열·화면 가림과 버티기/사격 동시 터치가 편한지.

## 핵심 방향

- 설치해서 실행하는 Android 앱을 목표로 합니다.
- 가상 이동 조이스틱 없이 화면 터치로 조준하고 발사합니다.
- 탄환은 공격 자원이자 이동 자원이며, 기본 재장전은 지상에서만 가능합니다.
- 반동 방향은 플레이어의 입력을 따릅니다. 탄환 조준 보조가 반동을 바꾸면 안 됩니다.
- Android 뒤로가기는 일시정지와 메뉴 조작에 사용합니다.
- 조작감 검증을 콘텐츠 확장보다 먼저 진행합니다.
- 낙하 중 기울기 보조는 실기기 실험 후 채택 여부를 결정합니다.

## 첫 개발 목표

- [ ] 원본 코드와 의존성을 검토하고 Android 빌드 기반을 구성합니다.
- [ ] 휴대폰에서 내려받아 실행할 수 있는 개발용 APK를 만듭니다.
- [ ] 반동 이동, 화면 터치 사격, 지상 재장전과 예약을 연결합니다.
- [ ] 뒤로가기 메뉴와 앱 중단·복귀 동작을 구현합니다.
- [ ] 짧은 이동 코스에서 착지와 조준의 조작감을 검증합니다.
- [ ] 리볼버·SMG·샷건과 보스 1종으로 작은 플레이 구간을 만듭니다.

## 개발 방식

변경마다 무엇이 달라졌는지, 어떤 확인을 했는지, 휴대폰에서 무엇을 확인하면 되는지를 한국어로 설명합니다. 코드 구조와 조절 가능한 수치는 문서로 안내합니다. 빌드 기반이 마련되면 자동 빌드와 APK 다운로드 안내를 추가합니다.

원본의 C++/raylib 구조와 LDtk 로더를 이식 검토의 출발점으로 삼습니다. 실제 재사용 범위와 Android 연결 방식은 빌드 검증으로 결정합니다. LDtk 편집기를 사용할 수 없어도 테스트 맵을 수정하고 실행할 수 있는 경로를 마련합니다.
