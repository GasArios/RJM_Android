# Gameplay Data

Future JSON, TOML, CSV, or custom data files should live here.

Recommended split:

- `weapons`: gun definitions, recoil profiles, durability, slots, and unique effects.
- `enemies`: normal monster definitions.
- `bosses`: boss definitions and phase tuning.
- `levels`: level metadata, traversal tier requirements, room links.
- `items`: consumable item definitions.
- `skills`: active and movement skill definitions.
- `enchantments`: modifiers and stacking rules.
- `quests`: main, side, and repeatable quest definitions.
- `dialogue`: NPC dialogue and localized text.
