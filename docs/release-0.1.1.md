# RJM Android 0.1.1 — 조작 패치

Galaxy S24 Ultra의 첫 실기기 피드백을 반영한 업데이트입니다.

- Android 가로 화면 비율에 맞춰 게임 영역을 넓혔습니다. 화면을 가로로 늘려 찌그러뜨리지 않습니다.
- 기본 배율을 0.8에서 1.10으로 높였습니다. 두 손가락을 벌리면 확대, 모으면 축소합니다. 배율은 0.65~1.80이며 저장됩니다.
- 뒤로가기 일시정지 메뉴의 `AIM MODE`에서 캐릭터 기준 / 화면 중앙 기준을 선택합니다. 기본값은 기존 캐릭터 기준입니다.
- 화면 중앙 기준은 중앙에서 손가락으로 향하는 방향으로 캐릭터가 발사합니다. 화면의 적을 직접 찍는 모드와 다릅니다. 중앙의 희미한 원은 사격하지 않는 작은 영역입니다.
- 빈 총의 다음 사격 입력은 원본 슬롯 순서대로 다음 발사 가능한 총으로 교체합니다. SMG 홀드에서 반자동 총으로 바뀌면 새로 탭해야 발사합니다.
- 모든 총이 비었을 때 새 탭은 전체 재장전을 예약합니다. `GUNS > RELOAD ALL GUNS`도 전체 재장전을 요청합니다. 공중 예약은 착지까지 유지됩니다.
- 전체 재장전 시간은 원본 그대로 장착 총 전체의 재장전 시간 평균이며 0.2~2.0초로 제한합니다. 공중에서는 시간이 진행되지 않습니다.
- 핀치 중 게임은 8% 시간으로 진행하고 사격은 멈춥니다. 모든 손가락을 뗀 뒤 새 터치로 사격합니다. BRACE와 사격은 핀치로 인식하지 않습니다.
- 즉시 사격을 유지하므로 플레이 중 첫 손가락을 누른 뒤 두 번째를 붙이기 전에는 한 발이 나갈 수 있습니다. 뒤로가기로 일시정지하고 메뉴 버튼 바깥에서 핀치하면 안전하게 조절할 수 있습니다.
- 조준 보조는 탄환에만 적용합니다. 중앙 기준에서는 화면에 보이고 벽에 막히지 않은 적에 최대 6도만 보정하며 반동은 원본 입력 방향입니다.

체크포인트 v1을 읽고 v2로 저장합니다. 안전 위치, 선택 총, 설정, 조준 모드, 배율을 복원하며 새 기동 시 체력·탄창·적은 초기화합니다.

자동 행동 검증, ARM64/x86_64 APK 빌드, Android 15 설치·터치·실제 두 손가락 입력·설정 저장/재기동 검증을 통과한 빌드만 공개합니다. Galaxy 실기기 조작감과 장시간 성능은 직접 확인해야 합니다.

테스트 APK의 서명 키는 빌드 환경에서만 생성합니다. 기존 앱과 서명이 달라 설치가 거부되면 기존 테스트 앱을 삭제하고 새로 설치해야 합니다. 이 경우 앱 내부 체크포인트가 초기화됩니다. 개인 서명 키는 공개하지 않습니다.
