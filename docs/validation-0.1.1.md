## 실행한 확인

로컬 C++ 행동 검증과 전체 소스의 PC / Android 조건부 컴파일 검사를 통과했습니다. GitHub Actions에서도 동일 행동 검증을 실행하고 ARM64·x86_64 APK와 별도 입력 검증용 테스트 APK를 빌드했습니다. apksigner 검증과 aapt 메타데이터 검사가 성공했습니다. APK의 체크섬을 공개 릴리스 digest와 대조했습니다. ARM64 `librjm.so`·`libc++_shared.so`의 모든 ELF LOAD 정렬은 16,384입니다.

행동 검증 범위:

- 프레임 사이 짧은 탭, 포인터 소유권, 버티기+사격, 메뉴 선택·닫기 입력 차단, 취소·화면 변경 후 새 입력
- 핀치 확대/축소 비율, 프레임별 증분 초기화, 손가락 하나만 남았을 때 사격 차단, 한 입력 묶음에서 끝난 핀치의 최종 배율 유지
- 일시정지 핀치, 넓어진 화면의 메뉴 히트박스
- 캐릭터/중앙 조준 벡터와 화면 Y 반전, 기준점의 작은 영역, 카메라 이동과 무관한 홀드 방향
- 3120×1440 전체 너비 좌표 변환, 확대 시 플레이어 화면 위치 유지, 줌 상하한과 작은 맵 경계
- 세트 재장전의 비만료 예약, 지상에서만 시작·진행, 모든 장착 총 평균(가득 찬 총 포함), 0.2~2.0초 제한, 타이머 중복 초기화 방지
- 원본 자동 교체 순서·발사 가능 조건, SMG 홀드에서 반자동 교체 시 새 탭 필요, 모든 총 소진과 일시적인 재장전/발사 대기 구분
- 중앙 기준의 탄환 보조: 최대 6도, 벽·화면 밖 후보 제외, 반동 방향 유지
- 원본 반동·버티기와 타일 착지

## Android 15 에뮬레이터

실제 APK 설치·네이티브 기동·터치 발사·총 선택·뒤로가기 일시정지·홈 화면 이후 복귀 시 일시정지를 확인했습니다.

별도 `ControlSmoke` APK가 플랫폼 MotionEvent 두 포인터를 게임 창으로 주입했습니다. 일시정지에서 조준 기준을 바꾸고 핀치 확대를 실행해 배율이 **1.10 → 1.25889**로 바뀌는 것을 확인했습니다. 이 구간에는 사격이 발생하지 않았습니다. 앱 내부 체크포인트는 `RJM_CHECKPOINT_2`이고 중앙 조준 모드와 배율을 저장했습니다. 프로세스를 종료하고 새로 시작한 뒤 로그에서 `restored aim=1 zoom=1.259`를 확인했습니다.

Actions의 `Android-smoke-evidence`에 로그와 화면 캡처가 있습니다. 게임 화면·무기 선택창·핀치 후 일시정지 화면을 직접 살펴 전체 가로 영역, 중앙 패널과 버튼 글자의 배치를 확인했습니다. 입력 주입 코드는 별도 테스트 APK에만 있으며 배포 게임에는 포함하지 않습니다.

## 설치와 남은 확인

0.1.0과 0.1.1 APK의 공개 서명 인증서를 비교했고 서명이 다릅니다. 기존 0.1.0은 삭제 후 0.1.1을 설치해야 합니다. 앱 내부 체크포인트는 초기화됩니다. v1 체크포인트를 읽는 분기는 구현했지만 이번 배포에서는 서명 변경으로 실제 덮어쓰기 마이그레이션을 시험하지 않았습니다.

즉시 발사를 유지하므로 플레이 중 첫 손가락이 처리된 뒤 두 번째를 붙이면 최초 한 발이 발생할 수 있습니다. 일시정지 핀치는 발사 없이 검증했습니다. 화면 중앙 조준의 실제 손가락 적응·고속 연사·가장자리 시스템 제스처와 장시간 성능은 Galaxy S24 Ultra에서 확인해야 합니다. 소프트웨어 GPU 에뮬레이터의 FPS는 Galaxy 성능 측정이 아닙니다.
