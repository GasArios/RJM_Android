# 모바일 조작 설계

사용자와 논의한 방향을 보존하기 위한 초기 문서다. 아래 항목은 구현 완료 목록이 아니다. PC 기획서 1.5 전체의 시스템과 콘텐츠는 이 문서에서 모두 확정하지 않는다.

## 목표

총을 쏴서 자기 몸을 조종하는 감각을 유지하면서, 화면의 가상 패드를 최소화한다. 조작감은 Galaxy S24 Ultra에서 실제로 테스트한다.

## 사용자 제안에 기반한 기본 방향

| 입력 | 동작 |
| --- | --- |
| 게임 화면 터치 | 캐릭터에서 터치 위치를 향해 조준하고 발사 |
| 배낭 버튼 | 배낭 열기 |
| 무기 버튼 | 느린 시간 상태에서 장착 무기 선택 |
| 스킬 버튼 2개 | 장착 스킬 사용 |
| 버티기 버튼 | 지상에서 반동과 미끄러짐을 줄이는 버티기 |
| 아이템 버튼 | 느린 시간 상태에서 아이템 선택 |
| Android 뒤로가기 | 일시정지 및 메뉴 조작 |

구석의 보조 버튼 위치와 크기는 손가락 가림, 오터치, 화면 여백을 고려해 실기기에서 정한다. 메뉴 열기와 스킬 버튼 등의 터치는 게임 화면 사격으로 전달하지 않는다.

## 조준, 사격, 반동

1. 터치 위치와 캐릭터 위치를 같은 좌표계로 변환한다.
2. 캐릭터에서 터치 위치로 향하는 입력 방향을 계산한다.
3. 반동은 입력 방향의 반대쪽으로 적용한다.
4. 탄환에 조준 보조를 적용하더라도 반동 계산에는 원본 입력 방향을 사용한다.

지속적인 목표 추적이나 조준 잠금은 기본 조작 방향에 포함하지 않는다. 탄환에만 적용하는 조준 보조의 범위와 강도는 조작감 검증에서 정한다.

연사 총기의 입력 방식은 아직 결정하지 않았다. 누르고 유지하는 방식을 시험한다면, 캐릭터가 반동으로 이동했다는 이유만으로 조준이 자동 회전하지 않게 한다. 터치 이동으로 의도적으로 조준을 바꾸는 동작은 별도로 처리한다.

캐릭터 중심에 가까운 터치는 방향 계산이 불안정하므로 처리 기준을 정한다. 작은 입력 오차로 반동 방향이 크게 뒤집히지 않는지 확인한다.

## 재장전 예약

- 탄이 없는 상태로 공중에서 사격 입력을 하면 재장전을 예약한다.
- 예약 상태에서 유효한 지상 착지가 확인되면 재장전을 시작한다.
- 탄이 없고 지상에 있다면 같은 입력으로 재장전을 시작한다.
- 예약을 넣은 입력으로 장전 직후 탄환까지 자동 발사하지 않는다.
- 기본 재장전은 공중에서 진행할 수 없다.

다음 항목은 구현할 때 정책을 정하고 문서에 추가한다.

- 예약이 어느 무기에 귀속되는지와 무기 교체 시 유지·취소 여부
- 부분 탄창의 수동 재장전 입력
- 재장전 중 피격, 다른 행동, 일시정지와 앱 중단 처리
- 버튼에서 시작한 터치가 게임 화면으로 이동한 경우의 입력 처리

원본에 빈 탄창에서 다른 총으로 자동 교체하는 동작이 있다면, 모바일의 재장전 예약과 충돌하는지 확인한다.

## 메뉴, 느린 시간, 앱 중단

- 플레이 중 뒤로가기는 게임을 일시정지하고 메뉴를 연다.
- 하위 메뉴에서 뒤로가기는 상위 메뉴로 돌아가도록 설계한다.
- 메뉴를 닫는 터치나 뒤로가기가 사격으로 이어지지 않게 한다.
- 무기·아이템 선택 중에는 게임을 매우 느리게 진행하고 선택 UI를 표시한다.
- 게임 시간에 속하는 이동, 탄환, 적 행동, 공격 간격, 재장전과 쿨타임은 같은 시간 정책을 따른다.
- UI 선택에 사용하는 시간과 게임 시간은 분리한다.
- 앱이 백그라운드로 가거나 입력 포커스를 잃으면 일시정지하고 진행 중인 터치를 해제한다.
- 복귀 직후에는 이전 터치가 사격이나 스킬 사용으로 이어지지 않게 한다.

종료 메뉴와 세이브 처리의 세부 규칙은 저장 시스템 구현 시 정한다.

## 실험 항목: 낙하 중 기울기 보조

사용자가 제안한 목적은 낙하 지점의 안정화와 미세 조정이다. 채택 여부와 기본 활성화 여부는 아직 확정하지 않았다.

실험 기준:

- 상승 중이나 지상에서는 이동 보조를 적용하지 않는다.
- 낙하 중에만 약한 수평 보정을 적용한다.
- 총 반동으로 얻은 수평 속도를 기울기 속도로 덮어쓰지 않는다.
- 현재 휴대폰 자세의 기준점, 작은 흔들림의 무시 범위, 보정 한도를 조절한다.
- 기능을 껐을 때도 초반 필수 경로를 통과할 수 있게 한다.
- 긴 낙하에서 보정이 누적되어 총기 해금 지형을 우회하지 않는지 확인한다.
- 기울기 보조가 별도의 이동·제동 스킬 역할을 대체하지 않는지 확인한다.

화면 기울기 입력은 센서 이름만 보고 정하지 않는다. 센서가 제공하는 값, 가로 화면 방향, 실제 손에 든 자세를 확인한 뒤 입력 방식을 선택한다.

## 첫 실기기 확인 항목

- 터치와 캐릭터 반동 방향이 일치하는가?
- 적을 맞히기 위한 탄환 보조가 착지 위치를 바꾸지 않는가?
- UI를 누르거나 닫을 때 오발하지 않는가?
- 빈 탄창에서 재장전 예약과 착지가 예상대로 이어지는가?
- 뒤로가기와 앱 중단·복귀 시 입력이 안전하게 해제되는가?
- 느린 시간 메뉴에서 모든 게임 동작의 시간 처리가 일관적인가?
- 가상 조이스틱 없이 이동과 보스 회피를 반복해도 피로가 과하지 않은가?
- 낙하 보조를 껐을 때와 켰을 때의 감각 차이를 설명할 수 있는가?
