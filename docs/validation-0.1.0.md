첫 CI의 SDK `tools` 패키지 요청은 현재 제공되는 `platform-tools`로 수정했다. 첫 에뮬레이터 실행에는 시스템의 전체화면 안내와 Google 홈 앱 오류 창이 터치를 가로챘다. 검증용 에뮬레이터 초기 설정을 정리한 뒤 전체 절차가 통과했다. 게임 프로세스의 네이티브/Java 크래시는 최종 로그에서 발견되지 않았다.

원본 게임에 실제 LDtk 맵·도트 에셋이 없어 원본 디버그 월드와 도형 그래픽으로 검증했다. 소프트웨어 GPU 에뮬레이터의 화면에는 약 16~18 FPS가 표시됐다. 이 수치를 Galaxy 실기기 성능으로 해석하면 안 된다.

## 아직 실기기에서 확인할 것

- S24 Ultra의 터치 조작감, 화면 가림, 버티기와 사격 동시 터치.
- 삼성 시스템 뒤로가기 제스처와 알림 창/잠금 화면 전환.
- 10분 이상 실행 후 프레임 안정성·발열·배터리.
- 실제 공중 사격과 착지를 반복하며 재장전 예약의 체감 확인.

테스트 APK는 임시 빌드 환경의 개발 키로 서명했다. 개인 서명 키를 저장소나 릴리스에 올리지 않았다. 다른 키로 서명된 후속 APK는 삭제·재설치가 필요할 수 있으며 내부 체크포인트가 지워진다.
