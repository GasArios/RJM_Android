# RJM Android — 고정 서명 APK

이 APK와 후속 고정 서명 APK는 같은 키를 사용합니다. 이전 **고정 서명 APK**를 설치했다면 새 APK를 열어 업데이트하면 됩니다. Android의 앱 데이터와 체크포인트는 유지됩니다.

0.1.2의 이전 임시 키 APK에서 넘어오는 경우에는 서명이 다릅니다. 고정 서명 APK를 처음 설치할 때 한 번만 기존 앱을 삭제해야 하며, 그때 앱 내부 체크포인트가 초기화됩니다.

네 가지 조작 모드와 게임 플레이는 [0.1.2](https://github.com/GasArios/RJM_Android/releases/tag/android-prototype-6)와 같습니다. 배포 전 Android 15에서 같은 서명의 이전 APK 위에 새 APK를 설치해 체크포인트와 내부 파일이 보존되는지 검증합니다.
