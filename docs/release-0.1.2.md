# RJM Android 0.1.2 — 네 가지 조작 방식

Galaxy S24 Ultra의 화면 중앙 조준 피드백을 반영해 오른손 조준·사격 패드를 추가했습니다.

- 뒤로가기 → 일시정지 → **CONTROL**에서 1 CHARACTER / 2 SCREEN CENTER / 3 AIM PAD / 4 TOUCH CIRCLE을 순서대로 선택합니다. 모드는 저장됩니다.
- 3번은 우측 하단 고정 원 안에 움직이는 작은 원이 있습니다. 4번은 같은 고정 원에서 작은 원을 표시하지 않습니다. 두 모드는 같은 입력 규칙으로 비교할 수 있습니다.
- 원 안의 중심 바깥을 누르면 그 방향으로 발사하고 반대 방향으로 날아갑니다. 길게 누르면 리볼버·샷건·SMG 모두 원본 공격 간격에 맞춰 이어서 발사합니다. 드래그하면 조준 방향이 바뀌며 원 바깥까지 끌어도 이어집니다.
- 중심으로 돌아오면 사격을 멈춥니다. 손을 떼면 즉시 멈추고 3번의 작은 원이 중앙으로 돌아옵니다. 당긴 길이는 반동 세기나 발사 속도를 바꾸지 않습니다.
- 빈 총에서 다음 발사 가능한 총으로 자동 교체하며 3·4번 홀드 사격은 계속 이어집니다. 모든 총이 비면 전체 재장전을 예약하고 손을 뗄 때까지 사격을 차단합니다. 착지 후 원본 평균 시간으로 장전하며 예약으로 장전 직후 오발하지 않습니다.
- HELP·BRACE·GUNS와 새 전체 **RELOAD** 버튼을 왼쪽에 배치했습니다. 왼쪽 RELOAD는 부분 탄창도 모두 장전하며 현재 홀드 사격을 차단합니다. 다시 쏘려면 실제 손을 떼고 새로 누릅니다.
- 3·4번에서 패드 밖 화면 탭은 발사하지 않습니다. 패드 밖 두 손가락 확대/축소는 유지합니다. 패드·왼쪽 버튼은 핀치나 다른 버튼으로 바뀌지 않습니다.
- 1·2번은 기존 조작을 유지합니다. 탄환 보정은 반동과 분리되며 뒤로가기·앱 복귀 일시정지도 유지합니다.

이번 테스트에서는 같은 구간을 3번과 4번으로 이동하고, 중심 복귀·재장전 후 재입력·자동 총 교체를 비교해주세요. 스킬·아이템·자이로는 아직 없습니다.

순수 입력·총기·좌표 검증과 Android 15의 실제 네이티브 터치 주입을 통과한 빌드만 릴리스합니다. 에뮬레이터 검증은 Galaxy의 손가락 감각·발열·장시간 성능을 대신하지 않습니다.

테스트 서명은 빌드 환경에서만 생성됩니다. 기존 테스트 APK와 서명이 다르면 기존 앱을 삭제한 뒤 설치해야 하며 내부 체크포인트가 초기화됩니다. 개인 서명 키는 공개하지 않습니다.
